# Multi-page Web Project

A student web-development project built as a collection of linked HTML pages. The repository includes separate pages for the home experience, login, buying, renting, and calculator flows.

## Project structure

| File | Purpose |
|---|---|
| `index.html` | Login / sign-up entry page |
| `homepage.html` | Main landing page |
| `buy.html` | Buying flow |
| `rent.html` | Renting flow |
| `calculator.html`, `rentcalc.html` | Calculator pages |
| `dashboard.html` | Dashboard page |

## Run locally

No build step is required for this static HTML project.

1. Clone the repository.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.
3. Navigate through the pages using the in-page links and buttons.

## Technologies

- HTML
- CSS
- JavaScript (where included in the pages)

## Project status

This is an academic front-end prototype. It is useful as a demonstration of multi-page navigation and interface construction; it should not be treated as a production commerce or rental platform. Backend services, persistent user accounts, payment processing, and production security are not documented in this repository.
